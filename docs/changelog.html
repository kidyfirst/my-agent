v0.1.1 2026-10-27 Latest

🚀 多模态视觉与消息交互体验 (Multimodal Vision & Chat UX)

  • 多模态视觉模型全面放开：修正模型视觉支持识别逻辑，放开对 deepseek-flash 等多模态模型的图片输入通道；采用 wrapLanguageModel 中间件消除 AI SDK v4 文件参数序列化为 null 导致的 400 异常。
  • 纯净消息交互体验：彻底移除服务端向用户提问注入提示文本的侵入式逻辑，保持用户气泡与数据库存储纯净一致。
  • 乐观消息对齐与防重击穿：升级消息对齐算法并加入时间戳判定，彻底修复大模型答复后用户消息重复追加到底部的显示缺陷。
  • 任务完成耗时统一感知：优化回复顶部指示，统一显示 Worked for x.xs 耗时信息，多步任务支持展开查看每个步骤细节。

🌐 官网文档与真实 UI 展现 (Documentation & Features)

  • 真实产品 UI 局部特性图：官网 5 大核心特性卡片全面升级为基于最新真实 UI 渲染的高清 16:9 拟物图。
  • 特性结构精简聚焦：移除冗余的 Codex 同心圆环说明，聚焦呈现专业自主 AI 编程底座。

v0.1.0 2026-10-26 Latest

🚀 核心架构与功能特性 (Core Features & Architecture)

  • 全新自主独立架构：自研核心调度引擎与 Agent 控制器，全面解耦第三方高依赖框架，提供轻量、高效的纯原生 AI 编程体验。
  • 自主 ReAct 执行闭环：支持大模型自主推理、规划步骤、受控调用工具、校验结果与自我修正。
  • 原生 MCP (Model Context Protocol) 支持：自研实现标准 MCP 协议客户端，支持 Stdio 子进程与 HTTP/JSON-RPC 传输通道，实现服务器动态发现、工具注入与生命周期管理。
  • 多模型生态接入：原生兼容并优化 Gemini (Gemini 2.5/3.8)、DeepSeek、Claude、OpenAI Codex 等主流模型，支持 API Key 零泄露本地安全存储。
  • Git Worktree 隔离工作空间：支持在独立 Git 工作树分支中运行 Agent 任务，零污染开发者当前主工作区代码，方便随时比对 Diff 与一键合并。
  • 原生内置全套工程工具：主 Agent 原生内置终端命令执行（execute_command）、文件受控操作（read_file, write_file, find_files, search_content）及精确 AST 语法替换（string_replace_lsp）。
  • 观察性记忆与会话秒级恢复：基于本地 SQLite（myagent.db）持久化管理历史会话与上下文记忆摘要，启动和切换项目时自动无缝恢复历史会话。

🛠️ 桌面客户端体验与系统优化 (Desktop App & UX)

  • 品牌与原生桌面支持：正式确立 My Agent 品牌名，应用安装后在 macOS 访达、启动台与程序坞中均正式显示为 My Agent。
  • Codex 风格同心圆环更新进度：应用内置自动更新系统，侧边栏更新按钮呈现类似 Codex 的同心动态圆环流光与精准进度指示。
  • 原生交互提示优化：优化侧边栏按钮悬停提示，采用原生 HTML title 属性彻底避免复杂浮窗被父容器裁剪遮挡。
  • 工作区幽灵项与空仓库修复：彻底修复工作区仅有一个项目时多出空白根目录的显示缺陷。
  • 全平台并行构建流水线：GitHub Actions 矩阵全自动发布 macOS (Apple Silicon & Intel)、Windows (x64) 以及 Linux (AppImage & deb) 安装包。
