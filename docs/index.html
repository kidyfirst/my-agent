Installation Guide

macOS 首次安装与打开提示

在 macOS 上若从浏览器直接下载并打开应用时提示「“MyAgent”已损坏，无法打开」或「无法验证开发者」，这是由于 macOS Gatekeeper 隔离属性所致。仅需在“终端”中执行以下命令清除隔离标记即可：

xattr -cr /Applications/MyAgent.app

执行完成后重新在应用程序文件夹中双击 MyAgent 即可正常启动运行。
